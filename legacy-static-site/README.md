# Legacy Static Site (v1 — আর্কাইভ)

এই ফোল্ডারটি **লেখক ফোরামের প্রথম সংস্করণ** — সম্পূর্ণ স্ট্যাটিক HTML সাইট
(`index.html`, `about.html`, `contact.html` ইত্যাদি)। বর্তমান ওয়েবসাইট এটা নয়।

- **বর্তমান সাইট:** `lekhok-forum/` ফোল্ডারের Node.js/Express অ্যাপ
- **স্ট্যাটাস:** আর্কাইভ/রেফারেন্স হিসেবে রাখা হয়েছে (git history-তেও সংরক্ষিত) —
  ডিজাইন, কনটেন্ট বা কপি দরকার হলে এখান থেকে ব্যবহার করা যাবে
- **Vercel-এ ডিপ্লয় হয় না** — Vercel প্রজেক্টের Root Directory `lekhok-forum` হওয়ায়
  এই ফোল্ডার ডিপ্লয়ে যায় না; চাইলে এটাকে আলাদা প্রজেক্ট হিসেবে (Root Directory =
  `legacy-static-site`) ডিপ্লয় করা সম্ভব
