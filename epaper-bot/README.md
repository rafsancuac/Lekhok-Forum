# লেখক ফোরাম — ই-পেপার বট 📰

**@ePaperXpress** টেলিগ্রাম-চ্যানেলের দৈনিক পত্রিকার PDF → গুগল-ড্রাইভ → সাইটের `/epaper` পেজে স্বয়ংক্রিয় প্রকাশ।

```
টেলিগ্রাম-চ্যানেল ──(GramJS)──▶ বট ──(ড্রাইভ-আপলোড+পাবলিক-লিংক)──▶ POST /api/epaper/sync ──▶ /epaper-পেজ
```

## সেটআপ (এক-বার)

```bash
cd epaper-bot
cp .env.example .env    # তারপর নিচের ৩টি ধাপ পূরণ করুন
bun install
```

### ① টেলিগ্রাম API (api_id + api_hash) — এখনো বাকি
1. https://my.telegram.org → **API development tools**
2. অ্যাপ তৈরি করে **api_id** ও **api_hash** কপি করে `.env`-এ বসান
   (ফোন-নম্বর `01859569175` আগেই দেওয়া আছে)
3. লগইন: `bun run login` → টেলিগ্রামে আসা **OTP** দিন → `.tg-session` তৈরি হবে

### ② গুগল-ড্রাইভ রিফ্রেশ-টোকেন — এখনো বাকি
- `.env`-এ ক্লায়েন্ট-আইডি/সিক্রেট আগেই দেওয়া আছে
- Google-Cloud-কনসোলে এই OAuth-ক্লায়েন্টে redirect URI **http://localhost:4288** যোগ করুন
- চালান: `bun run token` → কনসেন্ট-দিন → প্রিন্ট-হওয়া রিফ্রেশ-টোকেন `.env`-এ বসান

### ③ সাইট-সিঙ্ক টোকেন
- `.env`-এ `SITE_SYNC_TOKEN` = সাইট-সার্ভারের `EPAPER_SYNC_TOKEN` env-এর **হুবহু একই** মান
- `SITE_URL` = সাইটের ঠিকানা (লোকাল টেস্টে `http://localhost:8080`)

## চালান

```bash
bun start          # প্রোডাকশন (pm2: pm2 start "bun start" --name epaper-bot)
bun run dev        # ডেভ — ফাইল-বদলে অটো-রিস্টার্ট
```

বট প্রতি `POLL_MINUTES` (ডিফল্ট ২০) মিনিটে চ্যানেল স্ক্যান করে — আজকের নতুন PDF পেলে
ড্রাইভে আপলোড করে (যে-কেউ-পড়া-লিংক) এবং সাইটে ঠেলে দেয়। তারিখ-ভিত্তিক ডিডুপ
`.sync-state.json`-এ।

## সাইট-পাশ (এক-বার, সার্ভারে)

- env: `EPAPER_SYNC_TOKEN=<.env-এর সেই-একই-টোকেন>`
- API: `POST /api/epaper/sync` (Bearer) · `GET /api/epaper/papers` (পাবলিক)
- রেন্ডার: `/epaper` পেজ **শূন্য-পরিবর্তন** — `daily_content(content_type='epaper')` পুনঃব্যবহৃত
