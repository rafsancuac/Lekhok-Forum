## ২. টাস্ক ১৩ (পর্ব ৪) — বর্তমান অবস্থা

### অংশ ক (মাল্টি-ইমেজ) — ✅ সম্পন্ন, টেস্টেড, committed + pushed + লাইভ-যাচাইকৃত (`ed671f2`)

**ব্যাকএন্ড/ডেটা:**
- `post_images(entity_type, entity_id, image_url, sort_order, created_at)` জেনেরিক টেবিল — ৬ পোস্ট টাইপের জন্য।
- `post_images_v6_seeded` আইডেম্পোটেন্ট মাইগ্রেশন — বিদ্যমান `events.image_url`, `daily_content.image_url`, `press_clippings.image_url`, `posts.cover_image` → `post_images` (sort_order 0); মূল কলাম অক্ষত (backward-compat)।
- `getPostImages` / `setPostImages` হেল্পার (ডুয়াল sql.js/Turso)।
- `/admin/upload-images` (staff) + `/upload-images` (logged-in user) — JSON, সর্বোচ্চ ২০ ফাইল/রিকোয়েস্ট, WebP-অপটিমাইজ।

**পারসিস্টেন্স (সব ৬ টাইপ):**
- Notice (`notice`), Event (`event`), Daily (`daily`), News/press (`news`), Social/User Feed (`post`) — create + edit উভয়ই `setPostImages` সেভ করে।
- শেয়ার (share) করলে মূল পোস্টের সব ছবিও কপি হয়।
- মুছলে (trashDelete) `post_images` অরফান-ও মুছে যায়।

**আপলোড UI (reusable `multi-image.ejs` partial + `multi-image.js`):**
- multi-select, drag&drop, preview grid, drag-reorder, ব্যক্তিগত রিমুভ, লোডিং/সাকসেস/এরর স্ট্যাটাস।
- অ্যাডমিন (events/notices/daily) + মডারেটর (events/daily/notices/press) + ইউজার লেখা-ফর্ম — সব জায়গায় বসানো হয়েছে।

**ফ্রন্টএন্ড ডিসপ্লে (`post-gallery.ejs` partial + `post-gallery.js`):**
- ১ ছবি → আগের মতো একক `<img>` (কোনো গ্যালারি UI নেই)।
- ১+ ছবি → main + thumbnail strip (অ্যাডমিন-সেট ক্রম), ক্লিকে shared lightbox (prev/next/Esc), lazy-loading।
- ইভেন্ট, প্রেস, নোটিশ-বিস্তারিত, লেখা-তালিকা/বিস্তারিত, ফিড (dashboard), ডেইলি (epaper/on-this-day/activities) — সব পেজে লাগানো।

### অংশ খ (সেকশন-ভিত্তিক সেভ) — ✅ সম্পন্ন (`bac4436`, পুশড + লাইভ-যাচাই)

প্রতিটি এডিটেবল পেজ লজিক্যাল সেকশনে ভাগ করে প্রতি-সেকশন আলাদা AJAX সেভ — পুরো পেজ রিলোড হয় না। তিনটি সারফেসে লাগানো হয়েছে:

**১. কনটেন্ট এডিটর (`/admin/content`):**
- নতুন এন্ডপয়েন্ট `POST /admin/content/section` — একটি পেজের একটি মাত্র গ্রুপের ফিল্ড+ছবি সেভ করে; রিভিশন-হিস্ট্রি + অডিট + ইমেজ-মিডলওয়্যার রি-ইউজ করা হয়।
- `content.ejs`-এ প্রতিটি সেকশনে **সম্পাদনা → সেভ/বাতিল** বাটন; লকড অবস্থায় ফিল্ড `readonly`; সেভ `fetch` (X-CSRF-Token) দিয়ে, প্রতি-সেকশন স্পিনার + সাকসেস/এরর; বাতিল করলে প্রি-এডিট স্ন্যাপশট ফেরে।

**২. site_items সেকশন এডিটর (`/admin/sections` + `/moderator/sections`):**
- নতুন partial `admin/partials/sections-list.ejs` + `?partial=1` ফ্র্যাগমেন্ট রেন্ডার।
- সব অপারেশন (add/save/toggle/move/delete/reorder/undo) `_ajax=1` / `Accept: application/json`-এ JSON ফেরত দেয়; ক্লায়েন্ট partial রি-রেন্ডার করে (রিলোড নেই) + টোস্ট + আন্ডু বাটন।

**৩. পোস্ট এডিট ফর্ম (নোটিশ/ইভেন্ট/ডেইলি/নিউজ):**
- নতুন এন্ডপয়েন্ট: `POST /admin/notices/:id/section`, `POST /admin/events/:id/section`, `POST /admin/daily/:id/section`, `POST /moderator/press/:id/section` — শুধু পাঠানো ফিল্ড আংশিক-আপডেট + JSON।
- শেয়ার্ড JS `public/assets/js/section-form.js` (`LekhokSectionForm.init`) + `.sf-*` CSS।
- `notices/form.ejs`, `events/form.ejs`, `daily/form.ejs` — এডিট মোডে সেকশনে ভাগ (মূল তথ্য / বিষয়বস্তু / ছবি), অ্যাড মোডে আগের মতো একক ফর্ম।
- `moderator-press.ejs`-এর এডিট ফর্মও সেকশনে ভাগ।

**AC-যাচাই:** এক সেকশন সেভ → শুধু সেই সেকশন আপডেট (curl-যাচাই: title/content/images আলাদা আলাদা); পেজ রিলোড নেই; ভুল/খালি শিরোনাম → 400 JSON এরর, অন্য সেকশন অক্ষত; নোটিশ/ইভেন্ট/ডেইলি/নিউজ + সব কনটেন্ট পেজে কাজ করে (14 পেজ + 5 site_items সেকশন + 4 পোস্ট-টাইপ)।

### অংশ গ (মডারেটর প্যানেল UI/UX) — ⏳ এখনো শুরু হয়নি

## ৩. পরিদর্শনে পাওয়া গ্যাপ — ✅ সবই ঠিক করা হয়েছে

1. **`getTransportSchedule`-এ হারানো `try {`** — db.js সিনট্যাক্স এরর (সার্ভার বুটই হতো না)। ঠিক করা হয়েছে।
2. **EJS `<%#` কমেন্টে `%>`** — `post-gallery.ejs` ও `multi-image.ejs`-এর হেডার কমেন্টে `include(...) %>` থাকায় টেমপ্লেট পার্স-ফেইল (500)। ঠিক করা হয়েছে।
3. **press POST ভ্যালিডেশন বাগ** — শুধু মাল্টি-ইমেজ উইজেট দিয়ে ছবি দিলে (ফাইল/URL ছাড়া) ভুল "ছবি দিন" এরর। ঠিক করা হয়েছে।
4. **শেয়ার করা পোস্টে মাল্টি-ইমেজ হারানো** — share route শুধু `cover_image` কপি করত। এখন মূল পোস্টের `post_images`-ও কপি হয়।
5. **লাইটবক্স থাম্বনেইল-ইনডেক্স** — থাম্ব ক্লিকে সবসময় ০ নম্বর ছবি খুলত। এখন ক্লিক করা ছবির ইনডেক্স থেকে খোলে।
6. **`.lightbox-nav` CSS নেই** — গ্যালারি পেজ + নতুন পোস্ট-গ্যালারি দুই জায়গাতেই prev/next বাটন আনস্টাইলড ছিল। স্টাইল যোগ করা হয়েছে (গ্যালারি পেজও এখন সুন্দর হবে)।
7. **ডিসপ্লেতে single-image ফলব্যাক** — পুরনো ডেটায় `image_url`/`cover_image` থাকলে (মাইগ্রেশনের বাইরে) গ্যালারি খালি দেখাত। এখন `[image_url]` ফলব্যাক যোগ করা হয়েছে (events/daily/press/posts)।
8. **হেল্পার এক্সপোর্ট** — `getPostImages`/`setPostImages` মডিউল এক্সপোর্টে যোগ করা হয়েছে (আগে মিস ছিল)।

## ৪. পরিচিত সীমাবদ্ধতা / উন্নতির জায়গা (পরবর্তী)

1. **আপলোড ব্যাচ সীমা ২০ ফাইল** — টাস্কে "no numeric limit" বলা আছে; `post_images` টেবিলে সীমা নেই, কিন্তু প্রতি রিকোয়েস্টে ২০ ফাইল (multer `files:20`)। প্রয়োজনে বাড়ানো/সরানো যাবে — বাস্তবে ২০-এর ব্যাচ যথেষ্ট।
2. **প্রশ্ন (Q&A) টাইপে ছবি নেই** — টাস্কের ৬ টাইপে প্রশ্ন অন্তর্ভুক্ত নয় (Social/User Feed = `posts` টেবিলের article/feed), তাই আউট-অব-স্কোপ।
3. **`/about`-এর প্রেস মার্কি** টিকারে শুধু কভার (প্রথম ছবি) দেখায় — পূর্ণ গ্যালারি `/press`-এ। এটি ইচ্ছাকৃত (টিকার ডেকোরেটিভ)।
4. **নোটিশ-তালিকা পেজে ছবি নেই** (কমপ্যাক্ট লিস্ট) — বিস্তারিত পেজে গ্যালারি দেখায়। ইচ্ছাকৃত।
5. **আলাদা `gallery` টেবিল, achievements, members, resources** — single-image, টাস্ক-স্কোপের বাইরে (অডিটে উল্লেখিত)।
6. **ড্র্যাগ-রিঅর্ডার/লাইটবক্স ব্রাউজার-লেভেল ম্যানুয়াল টেস্ট** — DOM-রেন্ডার ও ডেটা-রাউন্ডট্রিপ যাচাই করা হয়েছে; ড্র্যাগ/লাইটবক্স ইন্টারঅ্যাকশন ব্রাউজারে ম্যানুয়ালি ভেরিফাই করার সুপারিশ।
